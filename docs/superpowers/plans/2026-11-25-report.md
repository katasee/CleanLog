# Report and WhatsApp Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A «Звіт» button on Statistics opens a sheet with the shown month's report, sent to WhatsApp in one
tap (or shared, when WhatsApp is missing) or copied.

**Architecture:** `ReportBuilder` (pure, `Formatting/`) learns the separate-only line; `WhatsAppLink` (pure,
`Formatting/`) percent-encodes the text into a `whatsapp://` URL; two small protocols (`URLAvailability`,
`Pasteboard`) hide UIKit behind `AppDependencies`; `ReportViewModel` (`Features/Report/`) observes the month and
exposes the title, subtitle, text, send action and copied state; `ReportView` lays it out and `StatsView`
presents it.

**Tech Stack:** SwiftUI, Swift Testing, String Catalog with generated symbols. No new dependencies.

**Spec:** `docs/superpowers/specs/2026-11-25-report-design.md` (product spec: Report, Report format).

## Global Constraints

- iOS 18.0+, Swift 6, default `MainActor` isolation; every type in `Models/` and `Formatting/` is `nonisolated`.
- The report text comes only from `ReportBuilder`; the October test (`reproducesTheOctoberReport`) stays green
  and unchanged.
- UIKit appears only in `App/` (the live `URLAvailability` and `Pasteboard`); view models import Foundation and
  Observation only.
- Every user-facing string is a `report.*` catalog key with Ukrainian and English; counts are plurals.
- Tests pin `today`, `Calendar` (`.warsaw`) and `Locale` (`uk_UA`, one `en_US` case per string builder).
- No comments in Swift; one argument per line for 3+ arguments; `swift-format lint --strict` clean.

## Review Focus

- A report with `+155` sent to WhatsApp → the chat shows `+155`, not ` 155` (Task 2 test
  `encodesThePlusSign`).
- The sheet open while the month's store changes (another tick lands) → the text follows (Task 4 test
  `followsTheStore`).
- Copy tapped twice within two seconds → the checkmark stays for two seconds after the **second** tap (Task 4
  test `copyingAgainRestartsTheConfirmation`).
- A month of the previous year paged back to → its title carries the year (Task 4 test
  `titleCarriesTheYearOfAnotherYear`).
- An empty month reached anyway (the button is disabled, but the store can empty under the sheet) → empty
  text, both actions disabled (Task 4 test `emptyMonthDisablesBothActions`).

## Plan review (2026-11-25, folded in above)

- `swift-concurrency-pro`: `holdConfirmation` used `try? await Task.sleep`, so a cancelled wait (a second copy)
  would fall through and clear the checkmark — now `do/catch` returns on cancellation. The two confirmation
  tests used 10/50 ms sleeps — now `.zero` and an hour with explicit cancellation, so neither depends on timing.
  `observe()` captures a fixed month, so it needs no month guard; no stored tasks.
- `swiftui-pro`: the empty month is a `ContentUnavailableView`; the card surface sits on the scroll view (a
  horizontal scroll view gives the text unlimited width, so no `fixedSize`); icon + text are `Label`s; the
  Statistics toolbar button needs `.labelStyle(.titleAndIcon)`; `presentationDetents([.large])` dropped as the
  default.

**Interfaces:**
- Consumes: `ReportBuilder.report(for:days:)`, `WhatsAppLink`, `URLAvailability`, `Pasteboard` (Tasks 1–3),
  `MonthStats.calculate(days:today:)` (`cleanedCount`, `workingDays`), `WorkDayRepository.days(in:)`.
- Produces:
  - `enum ReportSendAction: Equatable { case whatsApp(URL), share(String) }`.
  - `DayFormat.monthInTitle(_ month: MonthKey, includesYear: Bool, calendar: Calendar, locale: Locale) -> String`
    — `month(.wide)` (plus `.year()` when asked) with `capitalizationContext: .middleOfSentence`.
  - `@Observable @MainActor final class ReportViewModel`:
    - `init(month: MonthKey, today: DayKey, workDays: any WorkDayRepository, urlAvailability: any URLAvailability,
      pasteboard: any Pasteboard, confirmationDuration: Duration = .seconds(2), calendar: Calendar = .current,
      locale: Locale = .current)` — asks `urlAvailability.canOpen(WhatsAppLink.probe)` once, here;
    - `private(set) var title: String`, `subtitle: String`, `text: String`, `isCopied: Bool`, `copyCount: Int`;
    - `var hasReport: Bool` (`!text.isEmpty`), `var sendAction: ReportSendAction` (`.whatsApp(WhatsAppLink.url(for:
      text))` when available, else `.share(text)`);
    - `func observe() async` — `for await` over `days(in: month)`, rebuilding text and subtitle;
    - `func copy()` — `pasteboard.copy(text)`, `isCopied = true`, `copyCount += 1`;
    - `func holdConfirmation() async` — returns at once when `!isCopied`; else `do { try await Task.sleep(for:
      confirmationDuration) } catch { return }` (a cancelled wait leaves the checkmark), then `isCopied = false`
      — no `try?`, which would reset the state on cancellation. The view runs it in
      `.task(id: viewModel.copyCount)`, so a second copy cancels the first wait and starts a new one; no stored
      `Task`.
