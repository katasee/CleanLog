# Today Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** The Today tab: one screen for today, past and future days with the work timer, the day's and
the month's sums, ticking, removing, «Як учора», manual time on past days, and the two timer rules
(auto-stop on the last tick, a timer that overruns midnight records no time).

**Architecture:** Pure rules on `WorkDay` and new formatters first; then a `DayViewModel` per shown
day (approach 1 of the spec) tested against the fakes; then the SwiftUI screen on top. `TodayView`
holds only which day is selected (`TodaySelection`) and rebuilds `DayView(...).id(...)` per day.

**Tech Stack:** SwiftUI, SwiftData, Swift Testing, iOS 18.0+, Swift 6, default `MainActor` isolation.

**Spec:** `docs/superpowers/specs/2026-11-22-today-design.md` (read it with
`docs/superpowers/specs/2026-11-13-cleanlog-design.md`, sections Today / A future day / A past day).

## Global Constraints

- Every rule in `CLAUDE.md` and `.claude/conventions/`: no comments, no `!`/`try!`, `private` by
  default, 3+ arguments one per line, `nonisolated` on every `Models/` and `Formatting/` type.
- Every user-facing string is a `Localizable.xcstrings` key (`today.*`), Ukrainian and English, used
  through the generated symbol; plurals are catalog plural variations.
- Formatters live in `Formatting/`, follow `Locale.current` with templates; tests pin `Calendar.warsaw`
  and `Locale(identifier: "uk_UA")` / `"en_US"`.
- Money is `Money`; durations are `Duration`; a calendar day is `DayKey`.
- No Day plan button, no floating add button, no calendar button in this feature (spec Non-goals).
- Every `#Preview` that uses fakes sits inside `#if DEBUG`; UI branches also build Release.
- Records stay CloudKit-compatible: a new attribute is defaulted. The app has not reached TestFlight,
  so `SchemaV1` changes in place (as in CL-10).

## Review Focus

1. **Ticking the last apartment while paused** — the timer must finish at the tick's time, not stay
   paused (Task 2 `finishesAPausedTimerOnTheLastTick`).
2. **Ticking the last apartment on a past day** — no timer change, no `notToday` error (Task 2
   `ticksThePastDayLastEntryWithoutTouchingTheTimer`).
3. **An overrun timer from several days ago** (the app unopened for days) — every earlier day with an
   open session is dropped, not only yesterday (Task 3 `listsEveryEarlierDayWithAnOpenSession`,
   Task 8 `dropsOverrunTimersWhenShowingToday`).
4. **Setting the time by hand on a dropped day** — the «Час не записано» note goes away (Task 3
   `manualDurationClearsTheDroppedFlag`).
5. **«Як учора» when the template lost some of the apartments** — the count and the copy use only
   the remaining ones, at the current price (Task 1 `copiesOnlyTemplateApartmentsAtTheirCurrentPrice`,
   Task 6 `offersTheCopyWithTheFilteredCount`).
