# Calendar Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A calendar sheet, opened from the day header, that shows a month with each day's earnings and
opens any day on the Today tab.

**Architecture:** A pure `MonthGrid` lays out a month in `DayKey`s; `CalendarViewModel` observes the
shown month and the selected day through `WorkDayRepository` and turns them into cells, quick picks and a
card; `CalendarView` is layout only. `TodayView` presents the sheet and owns the day it opens.

**Tech Stack:** SwiftUI, Swift Testing, iOS 18.0+, Swift 6 with default `MainActor` isolation.

**Spec:** `docs/superpowers/specs/2026-11-24-calendar-design.md`

## Global Constraints

- Conventions in `.claude/conventions/` apply in full: no comments, no `print`, `nonisolated` on every
  `Models/` and `Formatting/` type, every formatter in `Formatting/`, every string through the catalog
  symbol with Ukrainian and English, plurals as catalog variations.
- Days are `DayKey`, months `MonthKey`; a `Date` appears only inside `DayKey`/`Formatting/` with an
  explicit `Calendar`.
- Earnings are `WorkDay.earned` — the same number the day screen shows.
- Tests pin `Calendar.warsaw` (or a copy with `firstWeekday` changed) and `Locale(identifier: "uk_UA")`.
- Branches stay 300–500 lines (`git diff --shortstat <base>...HEAD`); measure after each task.

## Review Focus

1. **A month starting on the week's first day** (June 2026 starts on Monday): no blank leading row —
   pinned in Task 1.
2. **A Sunday-first locale** (`firstWeekday = 1`): blanks and the weekday row both shift by one — pinned
   in Tasks 1 and 2.
3. **Paging away from the selected day**: the card keeps showing the selected day, the grid has no
   selected cell — pinned in Task 4.
4. **A tick while the sheet is open** updates the cell's amount — pinned in Task 3.
5. **A quick pick in another month** («Тиждень тому» on the 3rd) pages the grid back — pinned in Task 4.

## Plan review (2026-11-24)

- `swiftui-pro`: «Відкрити день»'s two-step action becomes a named method (Task 5). The one-type-per-file
  rule yields to the convention's supporting-type rule (`CalendarGrid`, `CalendarCellView` stay in
  `CalendarView.swift`). `.sheet(isPresented:)` stays: the sheet presents no optional data.
- `swift-concurrency-pro`: a `.task(id:)` restart cancels the old observation, but a value it already
  received can still land after the new one; both observations assign only while their captured key is
  still current (Tasks 3–4). No other findings: no stored tasks, the streams end with their task.

### Task 3: `CalendarViewModel` — the grid and paging

**Files:**
- Create: `CleanLog/Features/Calendar/CalendarViewModel.swift`, `CleanLog/Features/Calendar/CalendarCell.swift`
- Modify: `CleanLog/Resources/Localizable.xcstrings`
- Test: `CleanLogTests/Features/Calendar/CalendarViewModelTests.swift`

**Interfaces:**
- Consumes: Tasks 1–2; `WorkDayRepository.days(in:)`.
- Produces:
  - `struct CalendarCell: Identifiable, Equatable { let day: DayKey; let numberText: String; let amountText: String?; let isToday: Bool; let isSelected: Bool; let accessibilityLabel: String; var id: DayKey { day } }`
  - `@Observable @MainActor final class CalendarViewModel` with
    `init(selected: DayKey, today: DayKey, workDays: any WorkDayRepository, calendar: Calendar = .current, locale: Locale = .current)`,
    `private(set) var shownMonth: MonthKey`, `private(set) var selected: DayKey`, `var monthTitle: String`,
    `let weekdaySymbols: [String]`, `var weeks: [[CalendarCell?]]`, `func select(_ day: DayKey)`,
    `func showPreviousMonth()`, `func showNextMonth()`, `func observeMonth() async`.

Behaviour: `shownMonth` starts at `selected.monthKey`. `observeMonth()` iterates `days(in: shownMonth)` (the
month captured at the call; the view restarts it with `.task(id: shownMonth)`) into a `[DayKey: Money]` of
days whose `hasCleanedEntries`, replaced whole on every yield and assigned only while the captured month is
still `shownMonth` (a yield that reaches a cancelled observation after paging must not paint the old
month's map). `amountText` is `MoneyFormat.amount(earned)` for those days, `nil` otherwise.
Accessibility label: `DayFormat.dayAndMonth` plus, when earned, `MoneyFormat.string`, plus «сьогодні» on
today — keys `calendar.cell.earned` («%1$@, %2$@») and `calendar.cell.today` («%@, сьогодні» / «%@, today»).
`select(_:)` sets `selected` and, if it is in another month, `shownMonth`.
